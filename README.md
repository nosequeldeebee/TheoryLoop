# theoryloop

**A planted-mechanism benchmark for AI theory-building loops.**

Coding agents work in loops because every pass is checked by something outside
the agent: the compiler and the test suite. Social science has no compiler, so a
theory-building loop has nothing to stop it from confidently converging on
nonsense. `theoryloop` supplies the missing pieces:

1. **Worlds with known truth.** Synthetic NFT-project panels whose legitimacy
   outcome is generated by a mechanism we planted. Because we wrote the
   mechanism, we can score any theory a loop produces against it.
2. **Theory as code.** A theory is a list of executable propositions
   ("verification raises legitimacy when launched in a bear market"). Executable
   claims can be run on cases the builder never saw, so held-out cases act as a
   test suite.
3. **Subagent roles with separate contexts.** A *proposer* drafts theory, a
   *falsifier* tries to break it (controls, moderators, failures), a *reviser*
   applies the objections. The loop runs until the falsifier finds nothing.
4. **A ledger of every test.** Loops multiply forking paths. Every test any
   agent runs is logged, so the number of tests behind each claim is visible.

## Quick start

```bash
python -m unittest discover tests          # 10 tests, no API key needed
python run_benchmark.py                    # reference agents, 5 worlds x 50 seeds x 3 conditions (~45s)
export ANTHROPIC_API_KEY=...
python run_benchmark.py --backend llm --seeds 10              # Claude subagents
python run_benchmark.py --backend llm --seeds 10 --anonymize  # same, variable names hidden
```

Requires Python 3.10+, numpy, pandas, scipy, matplotlib, tabulate. The LLM
backend calls the Claude Messages API over HTTPS with the standard library.

## Worlds

| world | planted mechanism | failure mode it probes |
|---|---|---|
| `main` | verification raises legitimacy | finding a simple truth among distractors |
| `scope` | verification matters only in bear-market launches | missing boundary conditions |
| `confound` | community size drives both verification and legitimacy | decoy correlations |
| `null` | nothing | inventing theory from noise |
| `multi` | wash trading above 30% destroys legitimacy; creator reputation helps | multiple mechanisms, nonlinearity |

## Conditions

- `single_pass`: proposer only, no critique
- `loop`: proposer → falsifier → reviser, repeated until no objections
- `loop_holdout`: loop, then every surviving claim (including each scope condition) must hold on held-out cases

## First results (reference agents, 50 seeds per world)

| condition | recovered planted theory exactly | asserted a non-existent mechanism |
|---|---|---|
| single pass | 36% | 50% |
| adversarial loop | 60% | 37% |
| loop + holdout gate | 92% | 2% |

Full tables: `results/heuristic_summary.md`. Per-step ledgers for the first three
seeds of each cell: `results/heuristic_ledgers/`.

The reference agents are deterministic rules, not the object of study. They
validate the harness and set a floor. The research question is how LLM subagents
compare, and whether they find theory in the data or in their priors (the
`--anonymize` contrast).

## Layout

```
theoryloop/worlds.py   planted-mechanism data generators and truth sets
theoryloop/theory.py   propositions as executable claims; OLS tests
theoryloop/agents.py   proposer / falsifier / reviser; heuristic and Claude backends
theoryloop/loop.py     the loop, holdout gate, scoring against truth
theoryloop/ledger.py   log of every test run
run_benchmark.py       experiment runner, summary tables, chart
docs/technical_appendix.md
```
